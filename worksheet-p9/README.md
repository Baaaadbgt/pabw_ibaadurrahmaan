# PABW Meeting 9 — DOM, Events, and Interactivity

## Project
Personal profile page with a project list generated from JavaScript data, category filters, and a contact form with client-side validation.

## Files
- `profile.html`: page structure and element IDs.
- `css/style_profil.css`: page styling and responsive layout.
- `js/app.js`: project data and a pure category-filtering function.
- `js/dom.js`: DOM selection, dynamic rendering, event delegation, and form validation.

## How to run
Open this folder in VS Code and run `profile.html` using a local server (for example, Live Server). Check the browser Console for errors.
